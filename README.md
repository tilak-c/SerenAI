#  SERENAI  
##  AI-Powered Emotional Analytics Platform  

---

##  Overview  

**SerenAI** is an AI-driven emotional analytics web application built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)** integrated with **Gemini AI**.

The platform analyzes user chat inputs to detect emotional tone and visualizes daily mood patterns through interactive dashboards.

SerenAI is designed as a **mental wellness analytics system**, combining real-time sentiment detection with data visualization to provide meaningful emotional insights.
